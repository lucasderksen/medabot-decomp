44CDC dispatches modes zero through three to four later routines at 08064BEC, 08064C0C, 08064C2C and 08064C4C. D64 copies complete words and returns the uncopied byte remainder; D78 does the equivalent for halfwords. D90 copies the full supplied byte count. Word/halfword pointer alignment is a caller obligation reflected by the instructions.

D0C reads a word header and returns its upper 24 bits as a byte count. A high nibble of one in the first byte selects BIOS LZ77UnCompWram. The other path supplies CpuSet with `(header >> 10) & 0x1FFFFF`, then starts DMA3 with source and destination advanced by `header >> 9`, control `(header >> 10) | 0x80000000`, and a volatile completion read. These exact encoded operations are preserved without inferring another resource format. The source pointer is not advanced past the header before the CpuSet call. Taking the first byte before shifting reproduces the reference's byte-extraction instructions. The DMA view is scoped after CpuSet, and a distinct control local is initialized immediately before its OR/store; broader declaration scopes or a combined OR expression emit different instructions.

E64 maps the twelve valid OAM shape/size combinations to packed dimensions: high halfword is height, low halfword is width. Shape zero gives square dimensions 8, 16, 32 and 64; shape 4000 gives horizontal rectangles 16x8, 32x8, 32x16 and 64x32; shape 8000 gives vertical rectangles 8x16, 8x32, 16x32 and 32x64. Unsupported combinations return zero. Signed switch inputs reproduce the reference's comparison trees for the top-bit size encodings; this is a matching interface, not proof of the original typedef.

F54 does nothing for a null source. Otherwise it invokes D0C into the supplied scratch buffer and transfers the result into OBJ VRAM at 06010000 plus the narrowed tile index times 32. Its CpuSet path supplies word-copy mode and the encoded 21-bit count. Its DMA0 path preserves control 94000000, including its interrupt-enable bit, and performs a completion read. An ordinary u16 local alongside the narrowed u32 parameter explains the reference's duplicate retained tile registers.

45A14 writes 128 caller halfwords into offset six of 128 consecutive eight-byte OAM records, four writes per loop iteration. 45A40 returns one for y in -63..159 and x in -31..239, otherwise zero. 46CC8 conditionally transforms byte 0D of four 32-byte work regions at 030052D0, 03005290, 030052B0 and 030052F0 as `-value-2` modulo 256; negative corresponding arguments skip that region. 44DA8 changes the high two bits of OAM attribute zero according to the relative dimensions, then changes attribute one's size bits from the dimensions.
